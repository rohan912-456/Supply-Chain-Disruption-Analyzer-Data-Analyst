# Excel Analysis

The Excel workbook (`supply_chain_ready.csv.xlsx`, ~100 MB) is too large for GitHub hosting.

## What Was Done in Excel
- **Data Quality Audit:** Checked all 59 columns for nulls, duplicates, and data type issues across 180,519 rows
- **Data Cleaning:** Removed duplicates, fixed date formats, standardized numeric columns
- **Pivot Table Analysis:** Created pivot tables to analyze delivery delays by region, shipping mode, and product category
- **Key Finding:** Identified that 57.3% of all orders are delivered late — nearly 4x the industry benchmark of 15%
